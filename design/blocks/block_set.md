# Block set v1 (Milestone 7)

Status: **approved by the owner** (2026-10-09). Interview: 2026-10-09, 4 rounds.

## Summary
About 262 full-cube blocks: 16 tree woods plus 3 mushroom "woods", each
with the same set of variants; soils; the stone family; glass and ice; a
16-colour set (terracotta, stained glass, wool); and light blocks.
Textures are **16×16 pixel art** in a **vibrant, shaded** style. I draw
them (generated by a script, then hand-tunable), and the owner can repaint
any PNG; the game reloads it live. Shaped blocks (slabs, stairs, fences,
doors, trapdoors) are **milestone 7b**, right after M7.

## Mushroom woods (3)
Red, brown and glowing blue. Each has 8 blocks: `<m>_stem`, `stripped_<m>_stem`,
`<m>_cap` (top pattern: red with white spots, smooth brown, blue with glowing
spots), `<m>_gills`, `<m>_planks`, `carved_<m>_planks`, `mossy_<m>_planks`,
`<m>_bookshelf`.

## Soils & surface (10)

## Stone family (8)

## Glass & ice (4)

## Rendering rules
* opaque: most blocks.
* cut-out (alpha test): leaves. The `opaque_leaves = 1` graphics option renders them solid.
* translucent (blended): glass, tinted glass, stained glass, ice, crystalwood leaves.
* Animated: emberwood (cracks flicker), crystalwood and crystals (pulse),
  glowwood and the glowing mushroom (shimmer), smouldering leaves (embers).
* Every leaf block sways slightly (vertex animation).
