# VoxelB

[![Windows build](https://github.com/Notmoodo9/VoxelB/actions/workflows/build.yml/badge.svg)](https://github.com/Notmoodo9/VoxelB/actions/workflows/build.yml)

A voxel game written from scratch in x86-64 assembly (NASM) for Windows,
using Win32 and OpenGL directly.

**[⬇ Download latest build](https://github.com/Notmoodo9/VoxelB/releases/download/latest/voxelb-windows.zip)**
(Windows x64. Unzip it and run `VoxelB\voxelb.exe`. Built automatically from the default branch.
All builds: [Releases](https://github.com/Notmoodo9/VoxelB/releases/tag/latest).)
